# Homebase

Creature-collecting game: map editor, evolving DNA, turn-based battles, catching and breeding.

- `npm install` then `npm run dev` to play locally
- Pushing to `main` publishes to GitHub Pages: https://corbanirby.github.io/homebase/
- Design: `docs/design.md` · Sprites: `docs/sprites.md` · Notes for Claude Code: `CLAUDE.md`
